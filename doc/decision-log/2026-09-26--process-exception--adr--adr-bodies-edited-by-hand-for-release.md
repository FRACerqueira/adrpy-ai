Round 47's public-files pass found a local absolute path in ADR0004V01 and ADR0004V02, which ship in the sdist, and authoring-session phrasing ('this session', 'the same session') in ADR0004V02, ADR0005V01, ADR0006V01 and ADR0007V01. The normal rule (ADR files change only through adrpy commands) applies again (d3e900f).
