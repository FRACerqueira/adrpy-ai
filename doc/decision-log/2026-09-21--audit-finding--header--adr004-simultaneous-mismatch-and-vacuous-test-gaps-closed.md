# A comprehensive re-audit found a vacuous test and an untested two-mismatch case

**Front:** Test-Adequacy audit (round 21, comprehensive unfiltered pass) | **Severity:** Medium | **Resolution:** Direct | **Round:** 21

A round-21 comprehensive, unfiltered test-adequacy pass over the whole ADR004 area (not scoped to any single prior round's diff) found two gaps in the accumulated test suite, both mutation-confirmed. (1) test_config_allows_a_separator_change_that_adopts_nothing used an empty decisions folder, so it could not distinguish 'the adoption scan ran and correctly found nothing new' from 'the adoption scan never ran at all' -- disabling the check entirely still left it green. Fixed with a call-count spy on scan_decisions, proving the guard genuinely scans twice for a successful separator change. (2) Every existing marker/label mismatch test hand-edits exactly one status row at a time -- changing the second of two sequential mismatches.append(...) calls to an overwrite (mismatches = [...] instead of mismatches.append(...)) left the full suite green, since nothing constructs two simultaneous mismatches in the same file. Closed with a new test hand-editing both the Created and Changed rows at once, asserting both survive in order. Both closed in tests/test_config_command.py and tests/test_header.py.
