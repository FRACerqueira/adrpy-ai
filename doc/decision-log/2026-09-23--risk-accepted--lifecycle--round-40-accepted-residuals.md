# Round 40 residuals accepted: hidden headers, migrate false positives, final placeholder rejects

Accepted by the owner in Round 40, visible where noted. Eleven or more lines of front matter above a tool header push it out of the 12-line window, so migrate treats the file as having no header; widening the window would reopen false positives. A legacy file with an exact |--|--| table row, or a legacy UTF-16 file that never had a header, reads as a damaged header and blocks migrate -- the detail names the file. A mistaken reject of a migrated placeholder successor is now final (its whole family is the end of its line); supersede the predecessor again. A target outside folderadr is accepted by the per-file commands, as before Round 40. The order among family refusals differs between undo and version/revise, which only matters for hand-edited files.
