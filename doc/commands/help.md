# `adrpy help`

Lists every command, or describes one of them in full.

## Description

Lists available commands, or describes one command.

## Arguments

### `--command` *(optional, string, positional)*

Name of the command to describe.

## Example

```bash
# Describe one command in full
adrpy help new

# List every command
adrpy help
```
